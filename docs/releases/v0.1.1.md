# Release notes — v0.1.1 (backfilled)

**Backfilled** from the v0.1.1 tag and CHANGELOG after the fact, per the
[release-notes standard](../RELEASE-NOTES.md).

## Summary

**Recommended** if you had trouble enrolling; otherwise optional. This
release fixes one bug: enrolment was broken against the live server.

## What changed

- **Enrol fix (botid):** the server mints node IDs with an underscore
  prefix (`nd_…`), but the node's own ID validation rejected underscores —
  so enrol failed. The node now accepts underscores in node IDs. If your
  enrol previously failed with a node-ID validation error, this release
  un-breaks it. (PR #62.)
- Nothing else changed. Crawling, forwarding, politeness, and quarantine
  behaviour are identical to v0.1.0.

Full developer detail: `CHANGELOG.md` (v0.1.1 entry to be added).

## Egress / permission / privacy changes

No egress, permission, or privacy changes.

## Upgrade steps

1. Pull the new release (`git pull` the `v0.1.1` tag) and rebuild the
   image: `docker compose build`.
2. Restart the node: `docker compose up -d`.
3. If enrol previously failed, re-run it:
   `docker compose run --rm cl0q-node enroll --contact you@example.com`.

No config changes, no migration, no re-enrol needed if enrol already
succeeded on v0.1.0.

## Rollback steps

Redeploy the `v0.1.0` tree and rebuild. Rollback reintroduces the enrol
bug — do not roll back if you depend on the fix.
