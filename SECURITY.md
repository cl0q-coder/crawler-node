# Security Policy

## Reporting a Vulnerability

If you find a security vulnerability in this project, **do not open a public
issue**. Email [cl0qsearch@gmail.com](mailto:cl0qsearch@gmail.com) instead,
with:

- a description of the vulnerability and where it lives in the code,
- steps to reproduce it (or a proof of concept),
- anything you know about its impact.

You will get a reply confirming receipt. Fixes ship as soon as they are ready;
if the issue is being actively exploited, say so in your report and it will be
treated as urgent.

## Supported Versions

Security fixes go into the latest release on the default branch. Older tags do
not receive backports — upgrade to stay covered.
