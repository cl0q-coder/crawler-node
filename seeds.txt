# cl0q domain-crawler seed list
# One start URL per line. Blank lines and #-comments are ignored. A bare host
# (no scheme) is treated as https://. The crawler BFS-walks each of these to
# -max-depth, harvesting every external domain it finds into domain_info.
#
# Edit freely — domain-crawler reads this file when it starts. To apply changes:
#   docker compose up -d --build domain-crawler
#
# Picked for being link-rich AND bot-friendly (return real <a href> HTML, no 403
# / JS wall). reddit.com is deliberately absent — it 403s our User-Agent.
