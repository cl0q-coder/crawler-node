# Release notes — v0.1.0 (backfilled)

**Backfilled** from the v0.1.0 tag and CHANGELOG after the fact, per the
[release-notes standard](../RELEASE-NOTES.md).

## Summary

**Recommended** — this is the first public node release. A complete,
operator-ready crawler node: enroll in one command, verify with
preflight, run with Docker Compose. Five minutes from zero to crawling.

## What changed

This is the first release, so everything is new:

- **One-command enrol** (`cl0q-node enroll`): the server returns your
  `NODE_ID`, token, and refresh secret, stored in `cl0q-node.json` with
  mode `0600` (never printed or logged). New nodes start **quarantined**:
  your submissions land in a staging area until graduation (1,000
  content-hash-verified samples and 3 clean days, or at least one
  verified sample and 7 clean days flat).
- **Preflight self-check** (`cmd/preflight`): six PASS/FAIL checks before
  you start — local DB, ingest reachability, DNS, HTTPS egress, the
  SSRF guard, robots.txt fetch + parse.
- **Single-URL dry-run** (`SINGLE_URL=`): see exactly the JSON the node
  would send, without writing anything.
- **Startup config validation**: every knob validated at startup; bad
  values refuse to start with a clear error. Politeness floors are hard
  minimums — the node only ever gets gentler.
- **Bounded footprint**: `NODE_MAX_DOMAINS` / `NODE_MAX_PAGES` /
  `NODE_MAX_DB_GB` caps so the node can't eat your disk.
- **Observability**: Prometheus `/metrics` and a human `/status`
  endpoint per binary.
- **Operator docs** (`docs/NODE_OPERATORS.md`): 5-minute quickstart,
  stop/update/uninstall, troubleshooting, plain-language data & privacy.

Full developer detail: `CHANGELOG.md` § 0.1.0.

## Egress / permission / privacy changes

First release — this section documents the baseline the node establishes:

- **Outbound only.** Nothing listens on a public port. The node makes
  outbound HTTPS requests to web targets (crawling) and to cl0q's ingest
  server (forwarding results).
- **SSRF guard (netguard):** every outbound connection refuses
  private/loopback/link-local/cloud-metadata addresses.
- **Secrets:** enrol credentials live in `cl0q-node.json` (mode `0600`)
  and never appear in logs, errors, or terminal output.
- **Contact email:** optional but recommended at enrol — it's how cl0q
  reaches you if your node ever causes trouble. Nothing else personal
  is collected.

## Upgrade steps

N/A — first release. Fresh install:

1. `git clone https://gitea.cl0q.com/chris/crawler-node && cd crawler-node`
2. `docker compose build`
3. `docker compose run --rm cl0q-node enroll --contact you@example.com`

See `docs/NODE_OPERATORS.md` for the full quickstart.
